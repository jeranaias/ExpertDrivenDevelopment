Capability Gap Map

This document captures institutional capabilities Marines would deploy if access were granted. Compiled across training sessions, it forms the evidence base for tenant policy review at the HQMC AI working group level. A single Marine asking for a connector is a request. Forty Marines documenting the same blocked connector with beneficiary counts and time savings is a policy case.

Course 3.5 Artifact Course 4.5 Artifact Template

How to Use This Template

  1. During Course 3.5 Module 6 or Course 4.5 Module 6, fill at least one row per build (three rows minimum per Marine; Course 4.5 students add two rows tied to the Readiness Dashboard workflow).
  2. Be specific in "Blocking Permission / Tool." Name the connector, license, or admin grant. Generic "Power Platform access" is not actionable. "Office 365 Outlook connector blocked at tenant level" is.
  3. Beneficiary Count and Estimated Time Savings should be conservative and defensible. Round numbers are fine. Hours are fine.
  4. At the end of session, the instructor consolidates rows into a unit Capability Gap Map and forwards through the AI POC to HQMC.
  5. Rows are public-facing. No CUI, no PII. Use unit type, not unit name, when in doubt.

The Three Layers (Refresher)

Every row maps a gap between the Prototype Layer (what you built today in static HTML) and the Production Layer (what would be possible with full tenant access). The Spec Layer (genai.mil) is always available and is not the bottleneck.

Add Your Own Rows

The five rows above are examples. Pattern-match against your unit's actual builds. The most useful rows are the ones with a named blocking permission and a defensible beneficiary count. Vague gaps do not produce policy change. Specific gaps with numbers do.

What Makes a Strong Row

Field Weak (does not get acted on) Strong (gets reviewed)
Task Type "Training stuff" "Quarterly TEEP consolidation and S-3 brief generation"
Prototype Layer Solution "I built a thing" "Static HTML tool, deployed at github.com/<user>/teep, takes manual event entry, color-codes status, exports paragraph brief"
Production Layer Wish "Make it better" "Pull events from Outlook calendar via connector, sync resource holds against shared range schedule, notify attendees on cancellation"
Blocking Permission / Tool "Power Apps not allowed" "Office 365 Outlook connector restricted at tenant level. Dataverse environment not provisioned. SharePoint write-back outside of personal site disabled."
Beneficiary Count "A lot of Marines" "1 S-3 shop per battalion, 4 battalions in the regiment, weekly use"
Estimated Time Savings "Saves time" "3 to 5 hours per S-3 shop per week, conservatively. Annual: 150 to 250 hrs per shop."

What Happens to This Document

  1. End of session: instructor consolidates the room's rows into one Capability Gap Map.
  2. Instructor forwards to their unit's AI POC.
  3. AI POC forwards to the HQMC AI working group quarterly compilation.
  4. Each quarter, HQMC reviews the compiled gap map and prioritizes tenant policy changes. The strongest signal is repeat hits across units for the same blocking permission.
  5. When a gap is unblocked, the affected rows get marked CLOSED with a note about what was granted and when.

Instructor Note

Do not let students leave the session without putting at least one row in. The artifact is only useful if it is collected. A folder of training certificates without Capability Gap Maps is not the deliverable. The Capability Gap Map is the deliverable.
